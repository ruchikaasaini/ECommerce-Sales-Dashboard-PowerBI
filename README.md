# 📊 E-Commerce Sales Dashboard — Power BI

A professional **Power BI Dashboard** for analyzing E-Commerce sales performance with KPIs, trends, and regional breakdowns.

---

## 🚀 Project Overview

This dashboard helps business analysts and stakeholders track:
- 💰 Total Revenue & Profit
- 📦 Orders & Returns
- 🌍 Region-wise Sales Performance
- 📈 Monthly Sales Trends
- 🏆 Top Products & Categories

---

## 🛠️ Tools & Technologies

| Tool | Purpose |
|------|---------|
| Power BI Desktop | Dashboard Creation |
| DAX | Custom Measures & KPIs |
| Power Query | Data Cleaning & Transformation |
| Excel / CSV | Raw Data Source |

## 📈 Dashboard Pages

1. **Sales Overview** — Revenue, Profit, Orders at a glance
2. **Product Analysis** — Category & Sub-category breakdown
3. **Regional Map** — State-wise heatmap of sales
4. **Time Intelligence** — MoM & YoY comparison

## 📂 Dataset Columns

| Column | Description |
|--------|-------------|
| Order_ID | Unique Order ID |
| Order_Date | Date of Order |
| Product_Category | Category |
| Sales | Sale Amount (INR) |
| Profit | Profit (INR) |
| Quantity | Units Sold |
| Region | Sales Region |
| Customer_Segment | B2B / B2C |
